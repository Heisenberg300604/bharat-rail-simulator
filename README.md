# Bharat Rail Simulator 🇮🇳

A 3D Indian Railways train simulation game built as a personal game-development project.

The goal is to create an immersive railway experience inspired by Indian Railways, featuring realistic train driving, Indian railway environments, locomotives, passenger coaches, and railway operations.

## 🎮 Project Vision

Bharat Rail Simulator aims to let players experience operating Indian trains through detailed locomotives, recognizable railway environments, and engaging simulation gameplay.

The project will begin with a small playable prototype and gradually expand into a larger railway simulator.

## 🛠️ Technology Stack

- **Game Engine:** Unreal Engine 5
- **Gameplay Logic:** Blueprints initially
- **Programming:** C++ as the project evolves
- **3D Modeling:** Blender
- **Version Control:** Git and GitHub
- **Target Platform:** Windows PC
- **Graphics:** Unreal Engine real-time rendering

## 🚂 Initial Game Scope

The first playable version will include:

- One Indian electric locomotive
- One passenger coach type
- A basic railway track
- A small Indian railway station
- First-person locomotive camera
- External train camera
- Keyboard-based train controls
- Basic acceleration and braking
- Train horn
- A simple station stopping system

## 🎯 Development Philosophy

- Build a playable prototype before adding complex features.
- Learn game development through practical implementation.
- Keep the project modular and understandable.
- Use AI as a development assistant, not as a replacement for understanding.
- Prefer reusable systems over hardcoded gameplay logic.
- Optimize assets for real-time performance.
- Use properly licensed 3D models, textures, and audio.

## 📌 Current Status

**Planning and learning phase.**

The game engine and development workflow are being evaluated. The first milestone is to create a locomotive that can move along a railway track and stop reliably.
